## 📊 BlinkIT Grocery Sales Analysis & Interactive Excel Dashboard

# Project Summary

This project presents a comprehensive sales analysis of BlinkIT grocery data using Microsoft Excel. The goal is to transform raw transactional data into actionable business insights through data cleaning, KPI development, and an interactive dashboard.

The analysis focuses on evaluating product performance, outlet efficiency, customer satisfaction, and geographical sales trends to support data-driven decision-making.

# 🧾 Dataset Description

The dataset includes the following attributes:

Item Identifier

Item Type (Product Category)

Item Fat Content

Item Visibility

Item MRP

Outlet Identifier

Outlet Type

Outlet Size

Outlet Location Tier

Outlet Establishment Year

Sales

Customer Rating
